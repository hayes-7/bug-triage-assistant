3. 长尾类别（`input`、`buildsystem`、`import`）召回率显著偏低；
4. `reasoning` 字段内容笼统。

## 维护约束

| 约束 | 依据 |
| --- | --- |
| 一个评测批次对应且仅对应一个 Prompt 版本 | PD-07 第 2.3 节 |
| 批次执行期间修改提示词则该批次作废 | PD-07 第 8.2 节 |
| 版本对比须使用完整 300 条主评测集 | PD-07 第 8.3 节 |
| 调试性质的小样本执行不得记入本表 | PD-07 第 8.3 节 |
| few-shot 示例不得取自评测集 | PD-07 第 8.1 节 |
